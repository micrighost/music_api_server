# 🎵 Deemo 音樂電台 — 跨平台雲端串流系統

這是一個基於 **前後端分離 (Decoupled Architecture)** 架構打造的個人專屬音樂串流電台。
透過後端 API 基地即時發射音訊，並由輕量化的網頁端 (Web) 或手機端 (Flet App) 進行跨平台串流放歌。

---

## 🚀 系統架構圖 (Architecture Overview)

```text
    ┌──────────────────────────────┐
    │  Deemo 後端 API 發射基地      │
    │  (FastAPI + Uvicorn)         │ ───┐
    └──────────────────────────────┘    │
                   │                    │ 透過 ngrok 隧道
                   ▼                    │ 打破內網限制
           [ 41+ 首 MP3 歌曲 ]           │
                   │                    │
                   ▼                    ▼
    ┌────────────────────────────────────────────────────────┐
    │              全宇宙通用外網網址 (ngrok)                  │
    └────────────────────────────────────────────────────────┘
                   │                    │
          ┌────────┴────────┐  ┌────────┴────────┐
          ▼                 ▼  ▼                 ▼
  ┌───────────────┐ ┌───────────────┐ ┌───────────────┐
  │  本機測試網頁  │ │ 遠端手機網頁  │ │  Flet 手機App │
  │ (雙擊 index)  │ │ (LINE/瀏覽器)  │ │  (Android/PC) │
  └───────────────┘ └───────────────┘ └───────────────┘
```

## 🛰️ 後端：音樂發射基地 (API Server)

後端採用 **FastAPI** 撰寫，整合了標準的 **HTTP 206 斷點續傳 (Range Requests)** 機制，每次只將音樂切成精簡的碎塊 (Chunks) 射向前端，完美符合行動裝置的高效能串流規範。

### 📁 資料夾結構
```text
music_api_server/
├── songs/              # 🎵 放入所有的 .mp3 音樂檔案（目前已自動掃描 41 首）
├── image/              # 🖼️ 放入專輯封面圖片（包含：佩佩.jpg）
├── requirements.txt    # 📄 套件清單
├── api_server.py       # 🐍 FastAPI 主程式
└── index.html          # 🌐 前端遙控器畫面
```

### 📦 套件清單 (`requirements.txt`)
保持極致精簡，僅依賴核心網頁服務套件：
```text
fastapi
uvicorn
```

### 📡 支援的 API 路由發射台
1. **`GET /api/info`**：回傳電台當前狀態與最新的動態歌單 JSON 節目表。
2. **`GET /api/cover`**：直接發射二進位的專輯封面圖片。
3. **`GET /api/music/{song_name}`**：高階 HTTP 206 音訊串流服務。

---

## 🎛️ 前端遙控器一：萬能網頁版 (Web Client)

前端網頁不佔用任何硬體儲存空間，完全利用網頁非同步技術 (Fetch API) 跨網域拉取後端音訊。

### 💡 核心技術特點
* **突破 ngrok 封印**：程式碼內嵌萬能鑰匙標頭 `"ngrok-skip-browser-warning": "true"`，完美繞過免費版 ngrok 的防詐騙警告導頁。
* **自動擴充**：當後端 `songs/` 資料夾放入新歌時，手機 App 端完全無需重新修改、重新打包，打開便會經由 API 連線實現畫面的動態更新與無縫擴充！
---


### ⚙️ 環境配置與測試
1. 安裝環境套件：
   ```bash
   pip install -r requirements.txt
   ```
2. 發射API(保持運行才可以開始使用index.html)：
   ```bash
   uvicorn api_server:app --host 0.0.0.0 --port 8000 --reload
   ```
3. 開始使用：
* **直接雙擊開啟**：不需任何伺服器環境，本機直接滑鼠雙擊 `index.html` 即可跨網域點歌放音樂。
